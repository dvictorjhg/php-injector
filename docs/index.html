01 / first contact

Start at the boundary.

PHPInjector resolves constructor parameters through reflection. Register only the providers that need a name, an implementation, or preconfigured state; concrete classes can be resolved directly.

Install

The package requires PHP 8.4 or newer and PSR-11 2.0.

composer require dvictorjhg/php-injector

Resolve a class

Constructor dependencies are found from the injector's provider map.

final class ReportService
{
    public function __construct(
        private Logger $logger,
    ) {
    }
}

$injector = new Injector([Logger::class]);
$service = Injector::inject(ReportService::class);
02 / provider map

Register only what needs a name.

The constructor accepts an array or a Container. Class strings are lazy. Objects and scalar values are returned as supplied. A child injector can fall back to a parent provider chain.

Registration Meaning
Logger::class Register a concrete class by its own class name. It is constructed on first resolution and cached by default.
Formatter::class => HtmlFormatter::class Map an interface or alias to a concrete class. The alias and concrete class share one cached instance.
new RequestContext('cli') Register a prebuilt object. The injector returns the same object, preserving caller-owned state.
Closure::class => $handler Register a closure under its type for a parameter typed as Closure.
'env' => 'production' Register a named scalar or context value for a parameter using #[Inject('env')].
!
One lifecycle detail matters.

Every new Injector becomes active. Without an explicit parent, it falls back to the previously active injector, forming a provider staircase. Static calls use the active injector.

03 / object identity

Choose the owner of identity.

There is one default and two deliberate escape hatches. The injector caches ordinary automatic construction; a class can opt out, or own construction itself.

Default cache

Automatically constructed classes are cached in the active injector. A newly constructed injector has its own cache and can fall back through the previous injector staircase.

#[Transient]

Mark a class to skip injector-managed cache writes and receive a fresh automatic construction. An explicitly registered object and a class's own factory still win.

Singleton

Implement getInstance() when the class must control creation. The injector delegates to that method instead of calling the constructor.

use PHPInjector\DI\Attributes\Transient;

#[Transient]
final class RequestStamp
{
}

$first = Injector::inject(RequestStamp::class);
$second = Injector::inject(RequestStamp::class);

$first === $second; // false
04 / parameter resolution

Read the lookup chain.

For every constructor, method, closure, or function parameter, the injector stops at the first matching source. Explicit values are the strongest signal.

01

Explicit args

Type key, parameter name, then numeric position.

02

#[Inject]

Use the named provider ID from the parameter attribute.

03

Typed provider

Look up a non-builtin named class type.

04

PHP default

Use the parameter default when no provider matches.

05

Exception

Missing required values raise InjectorException.

Argument arrays must use one key style per call. Mixing integer and string keys is rejected so positional and named intent cannot be confused.

Automatic type lookup supports registered non-builtin named types, including classes, interfaces, abstract classes, enum instances, nullable named types, and Closure providers. Built-in types, callable, untyped parameters, and union or intersection types require an explicit argument or #[Inject('id')]. Variadics accept zero or more values.

A named Closure provider and a list-valued class provider can be used together:

use PHPInjector\DI\Injector;

final class Logger
{
    public function __construct(public string $channel)
    {
    }
}

final class ReportBatch
{
    public static function channels(Logger ...$loggers): string
    {
        return implode(',', array_map(
            static fn (Logger $logger): string => $logger->channel,
            $loggers,
        ));
    }
}

$injector = new Injector([
    \Closure::class => static fn (string $value): string => strtoupper($value),
    Logger::class => [new Logger('api'), new Logger('worker')],
]);

$formatted = Injector::inject(static fn (\Closure $format): string => $format('ready'));
$channels = Injector::inject([ReportBatch::class, 'channels']);

echo $formatted . PHP_EOL;
echo $channels;
05 / injection targets

More than constructors.

The same parameter resolver works across class construction and callable invocation. Method arrays accept either a class name or an existing object.

  • Class name ReportService::class resolves its constructor.
  • Method array [ReportController::class, 'show'] or an object target.
  • Callable string 'ReportJobs::warm' or a global function such as 'strlen'.
  • Closure A closure receives providers and explicit values by parameter.
  • Invokable object An object with __invoke() is resolved as a callable. 
final class ReportJobs
{
    public static function warm(Logger $logger): string
    {
        return "warming {$logger->channel}";
    }
}

Injector::inject('ReportJobs::warm');
Injector::inject(
    static fn (Logger $logger): string => $logger->channel,
);
Injector::inject('strlen', ['string' => 'cache']);
06 / public API

Small surface, explicit edges.

Use the API map below when you need the exact ownership boundary. The source links point directly to the implementation on GitHub.

Remember: The latest constructed Injector is active. Use Injector::inject() or PHPInjector\DI\inject() to resolve through it and its parent staircase.

Injector::__construct()

Accepts an array or Container of providers and an optional parent injector. Without an explicit parent, the previous active injector becomes the new injector's parent and the new instance becomes active.

src/DI/Injector.php
Injector::inject()

Statically resolves classes, method targets, closures, functions, callable strings, and invokable objects through the active injector.

src/DI/Injector.php
Injector->addProvider()

Stores or replaces a provider by explicit string ID. Class-string providers remain lazy until resolution.

src/DI/Injector.php
PHPInjector\DI\inject()

Global function entry point for Injector::inject(), using the active injector.

src/DI/functions.php
Container

PSR-11-compatible storage with has(), get(), set(), unset(), count(), and iteration.

src/Container/Container.php

Parameter attribute for selecting a named provider, especially useful for scalar or contextual values.

src/DI/Attributes/Inject.php

Class attribute that opts automatic construction out of injector-managed caching.
